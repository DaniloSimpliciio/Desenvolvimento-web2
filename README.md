# Desenvolvimento Web 2

Repositório destinado às atividades práticas e exercícios desenvolvidos durante a disciplina de Desenvolvimento Web 2 do curso de Análise e Desenvolvimento de Sistemas.

## Objetivo

Aplicar conhecimentos de desenvolvimento de aplicações web, explorando conceitos de programação, desenvolvimento back-end e front-end, APIs e integração com banco de dados.

## Tecnologias e ferramentas

- Java
- Spring Boot
- Angular
- MySQL
- HTML
- CSS
- TypeScript
- Git e GitHub

## Organização

O repositório reúne atividades acadêmicas, exercícios e implementações desenvolvidas ao longo da disciplina.
